# Signal Logo Notes

The logo should communicate attention, judgment, and direction. It should not look like a generic AI app, fintech promo, or trading bot.

## Best Direction

The strongest first direction is **01 / Folded vector**.

Why:

- It feels like attention being routed.
- It suggests a decision path without using a chart/candlestick.
- It works as a small app icon.
- It is serious enough for a financial product.
- It separates the product from Robinhood while still feeling compatible with brokerage data.

Meaning:

```text
Signal turns market noise into directed attention.
```

## Second-Best Direction

**02 / Decision path** is the best alternative if the brand should feel more agentic.

Why:

- It shows a research path resolving into a direction.
- It fits the autonomous assistant concept.
- It makes the agentic loop visible without using robot/AI imagery.

Risk:

- It is slightly more complex at small sizes than the folded vector.

## More Abstract Direction

**04 / Crossing axes** is the most premium and abstract.

Why:

- It suggests multiple signals crossing into conviction.
- It is less obvious and could feel more like a frontier-lab product.

Risk:

- It may be too abstract before the product is established.

## Trust / Memory Direction

**06 / Research ledger** is strongest if the product identity leans into scorecard, proof, and case files.

Why:

- It says record, thesis, audit trail, proof.
- It aligns with the Memory and Scorecard pages.

Risk:

- It may feel more like accounting or document software than a market operating system.

## Avoid

Avoid:

- green dot identity,
- literal brain icon,
- robot/sparkle AI branding,
- candlesticks,
- crypto-style marks,
- Robinhood visual language,
- overly playful fintech illustration.

## Recommended Brand Lockup

```text
[folded vector mark] Signal
```

Connection state should be separate:

```text
Signal        Robinhood read-only
Signal        3 accounts connected
Signal        Sync issue
```

The brokerage is a data source, not the brand.
